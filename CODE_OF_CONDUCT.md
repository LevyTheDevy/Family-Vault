# Code of Conduct

## Our Standards

FamilyVault is a tool built for families. Contributions and community interactions should reflect that spirit.

We expect everyone participating in this project to:

- Be respectful and constructive in discussions and code reviews
- Focus feedback on ideas and code, not on individuals
- Accept that maintainers have final say on the direction of the project

We will not tolerate:

- Harassment, abuse, or discriminatory language of any kind
- Sharing, requesting, or discussing illegal content — including any content that sexually exploits minors
- Spam, off-topic promotion, or bad-faith contributions

## Scope

This applies to all project spaces — GitHub Issues, Pull Requests, Discussions, and any other official channels.

## Enforcement

Violations may result in comments being removed, contributions being rejected, or the person being permanently banned from the project. Report concerns to levieichelberg2000@gmail.com.
